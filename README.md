## 👾 Who is Jorge?

I've spent more than 20 years playing the story mode of Mexican game development: founding studios, growing teams and opening doors from Guadalajara. I founded **KaraOkulta**, today I lead **Amber Studio México**, and I keep building where video games, business and AI meet.

My main mission hasn't changed: **help more people make a living making video games**. If you're building something interesting, the co-op slot is open.

## 🤖 How I build with AI

I come from running studios and companies. Today I ship software by directing AI agents: I write the spec, Claude Code, Codex and Cursor write the code, and changes go out with a backup, a rollback plan and a postmortem. Most of what you see below was built that way.

Behind it runs **PapacitoOS**, my personal operating system: specialized agents, shared memory and follow-up loops. The code stays private while it matures, and it has a [public page](https://os.jorgesuarez.com.mx).
